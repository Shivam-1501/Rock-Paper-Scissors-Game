## Project Description
The Rock Paper Scissors Game is a C++ application where the user plays against the computer. The computer chooses its move randomly and the program decides the winner of each round based on the game rules.

## Features
- Accepts player name.
- Takes the player's choice (Rock, Paper or Scissors) as input.
- Computer selects a random move.
- Decides the winner of each round.
- Allows the user to play multiple rounds.
- Shows the running score after every round.
- Tracks winning streaks with a special message for 3+ wins in a row.
- Displays the final scoreboard with win percentage and a fun rating.

## Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choice is a draw

## Technologies Used
- C++
- Classes and Objects
- Encapsulation (private data members, public methods)
- Constructor
- Conditional Statements and Loops
- Input/Output Operations
